# iot-multinode-dashboard
A modular, LAN-based IoT framework featuring multi-MCU firmware (ESP32, STM32, etc.), web dashboard, mobile apps, and hardware PCB designs.

## 🧭 Project Navigation (快速导航)

| Module | Path | Description |
| :--- | :--- | :--- |
| **Firmware** | [`/firmware`](./firmware) | 多芯片底层固件源码（ESP32, STM32 等） |
| **Web Dashboard** | [`/web`](./web) | 局域网网页端监控与控制面板 |
| **Mobile App** | [`/app`](./app) | 跨平台移动端控制应用 |
| **Documentation** | [`/doc`](./doc) | 架构设计、通信协议及开发指南 |
| **PCB Hardware** | [`/pcb`](./pcb) | 硬件原理图与 PCB 设计源文件 |
